# Spline_VS_Autocorrélation
Demonstration de l'impacte d'une dépendance temporelle sur une estimation de tendance par spline_Objectif : montrer, dans des expériences contrôlées et reproductibles, comment la prise en compte de l’autocorrélation peut améliorer la sélection du lissage, l’estimation du signal et l’évaluation de l’incertitude.
